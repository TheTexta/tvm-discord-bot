# Security reporting

Report vulnerabilities privately through [GitHub’s security advisory form](https://github.com/TheTexta/tvm-discord-bot/security/advisories/new). Do not publish member data, credentials, or exploit details in public issues.

Include the affected revision, reproduction steps, impact, and a proposed mitigation if available. Use synthetic accounts and addresses. The maintainer will coordinate fixes and disclosure through the private advisory; there is no guaranteed response time.

Security fixes target the current `main` branch. Operators should keep deployed source and dependencies current, use one replica, protect database backups, and follow [the operations guide](docs/operations.md).

# Upstream archive

These files document the original [EmailVerify](https://github.com/lkaesberg/EmailVerify) project. They are retained for attribution and historical reference; its premium features, APIs, deployment configuration, legal pages, and website branding do not describe this TVM bot.

For supported TVM behavior and setup, use the [repository README](../../README.md). The original project README is [UPSTREAM_README.md](UPSTREAM_README.md).

The upstream site files are an archive, not a maintained website build. Their original paths and external links have not been updated.
